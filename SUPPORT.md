# Support

- Use [GitHub Discussions](https://github.com/arduano/p2prpc/discussions) for architecture questions, deployment guidance, and general help.
- Use [GitHub Issues](https://github.com/arduano/p2prpc/issues) for reproducible bugs and focused feature requests.
- Use [private vulnerability reporting](https://github.com/arduano/p2prpc/security/advisories/new) for security vulnerabilities.

This is an open-source project without a guaranteed response time or commercial support commitment. Never include credentials, private endpoint keys, access tokens, capability handles, sensitive locator tickets, or confidential file content in a report.
